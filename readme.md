# 👋 こんにちは、kosuke-17 です

React / Next.js を軸にしたフロントエンドエンジニアです。
最近は **AI エージェントに開発そのものを任せる仕組みづくり** に夢中で、
skill / subagent を組み合わせた開発体制を設計しては、実際のプロダクトで回して試しています 🤖

- 🔭 いま作ってるもの: AI エージェント用の skill・subagent 体制、Claude Code を安全に動かす devcontainer
- 🧠 関心ごと: 企画（PRFAQ）→ UX 設計 → DDD モデリングまで、実装の**手前**の工程を AI と一緒に回すこと
- 📚 知識管理: Obsidian + Claude Code で「外部知識」と「自分の意思決定履歴」を別々の Wiki に蓄積中
- 🧰 ふだん使い: TypeScript / React / Next.js / NestJS / Python / Tailwind / Prisma

## 📌 Pickup Repositories

### [dev-container-setup](https://github.com/kosuke-17/dev-container-setup)

`claude --dangerously-skip-permissions` をホストから隔離して動かすための devcontainer テンプレート。
egress firewall つきで、残っているリスクもドキュメントに明記しています。

### [ddd-collaborative-modeling](https://github.com/kosuke-17/ddd-collaborative-modeling)

ドメインエキスパートが自分1人しかいない環境で、DDD の協働モデリングを成立させるための skill / subagent 群。
EventStorming とドメインストーリーテリングを AI ロール（アーキテクト・懐疑派・書記）と回して、
確定した理解をユビキタス言語辞書・ドメインモデルとして残します。
